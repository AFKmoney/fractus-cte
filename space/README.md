# Fractus — Continuous Cognitive Agent

A living AI that thinks continuously, remembers forever, and grows on its own.

Not a transformer. A **dynamical system** with:
- **Continuous thought** — persistent state, tick by tick
- **Kuramoto oscillator clock** — phases drive expert routing
- **Sparse MoE** — 2 of 128 experts active per token
- **Persistent memory** — remembers across sessions

**1B parameters** trained on 4.23B tokens of neuroscience, esoteric tradition, code, and Fractus's own identity.
